# Host Plan Tests

Host Plan Tests are a specialized form of activation tests designed to ensure that a plugin can be installed and deactivated successfully alongside a host plan offered by WooCommerce.com. These tests are crucial for verifying basic compatibility with hosting environments provided by partners such as GoDaddy or Bluehost.

## Overview

Host Plan Tests focus on the following key aspects:

- **Installation**: Verifying that the plugin can be installed without issues in the hosting environment.
- **Deactivation**: Ensuring that the plugin can be deactivated successfully without causing any disruptions.


## Important Considerations

- **Dynamic Extension Lists**: The specific extensions included in a host plan are subject to change based on ongoing negotiations with hosting partners. As such, the list of extensions is not publicly shared.
